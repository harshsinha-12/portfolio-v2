AI agents are becoming more capable, but capability is not the same as learning.

An agent can recover from a tool error inside one run and still begin the next similar task from zero. A genuinely improving system needs to turn past experience into a better future decision—and prove that the change does not create regressions.

My new article develops a practical architecture for doing that with:

- personal, workspace, and global memory scopes;
- structured, replayable trajectories;
- sandboxed experimentation;
- candidate memories instead of unrestricted self-rewriting;
- regression evaluation, staged promotion, and rollback; and
- observability that measures outcome improvement rather than retrieval volume.

The central argument is intentionally narrow: memory is not sufficient for intelligence, but it may be the coordination layer that allows agent experience to compound safely.
