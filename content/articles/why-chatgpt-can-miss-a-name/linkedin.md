# LinkedIn launch copy

A name can be missing from ChatGPT's Memory summary and still be sitting in an old chat.

I wrote through the public behavior of Dreaming, the 4 June 2026 memory update, and the comparison that kept bothering me. Gray matter changes synapses. This system writes a briefing beside a model whose weights stay put.

The charts are the useful part. On Plus and Pro memory, factual recall moved from 41.5% in the 2024 saved-memory system to 82.8% with Dreaming V3. The time task, the one where a finished trip should stop being a current trip, moved from 9.4% to 75.1%.

Those are OpenAI's evaluations. About 17% of the recall tasks still miss. The help center is also explicit that the summary is a high-level view, and that ChatGPT does not search history on every reply.

The piece has the architecture, both charts, a side-by-side with human memory systems, and a test you can run on your own account. Find a fact the summary dropped, then ask a new chat for it.
